## Problem statement

Vlad's first Series, _Building an agent from scratch_, still has a placeholder Draft as Part 1. The real Part 1 already exists as a lesson written in his OpenCode fork (`/Users/vladex/PLAYGROUND/opencode/lessons/0001-the-agent-loop.html`, generated by another Claude session while exploring that repo). ## Solution

Replace the placeholder with a faithful port of the lesson: same content, code, transcripts and sources, lightly edited for the blog (learning-in-public voice, first person where the lesson says "in my runs"). It stays a Draft until Vlad has read it in `bun run dev`. The Series introduction and Planned Parts are updated to match the lesson roadmap.

Decisions (settled in the planning session):

- **One Post**, not several. llama.cpp and the Claude section stay in the Post, clearly marked optional.
- **Light edit.** Lesson-pack scaffolding goes: the nav links, "Reference: Agent architecture", glossary links, the "ask Claude" paragraph, the "Primary source for this post" section (merged into the final Sources list). References to other lessons become "Part N" with the Planned Part title in italics, e.g. "_Tools as data_ (Part 3)". "Part 2 prediction, now observed" is reworded to point at the next Part, _The roadmap_.
- **Test environments.** Keep both (M4 Max for the build and transcripts; M1 16 GB for the early wire capture), worded so the two datasets are clearly distinct. The disclaimer that the Claude steps were never run live, and the "shape of a run, not recorded output" note, are removed: the Claude section was run and works.
- **Quizzes** ("Check yourself", three questions) become native `<details>` blocks: question, options, answer revealed on click. No JavaScript.
- **Lesson blocks map to plain Markdown.** Callouts become blockquotes with a bold label; step lists become ordered lists; transcripts become `text` code blocks (they get the copy button); the OpenAI-vs-Anthropic comparison becomes two captioned code blocks stacked vertically (no sideways scrolling on a phone). The "Stuck? The finished file" and "Under the hood" blocks become `<details>`, with a few lines of CSS in `global.css`. No new Astro components; the file stays `.md`.
- **External links** are plain Markdown links (same tab). The pinned OpenCode link stays.
- **Agent vocabulary** (provider, protocol, step, turn…) is defined inline in the Post. `GLOSSARY.md` is unchanged: it covers the blog's domain, not the subject matter.
- **Frontmatter:** title "The agent loop"; description "An AI coding agent is a short loop around a model. I build one in plain TypeScript and run it on Ollama, llama.cpp and Claude."; `category: agentic-ai`; `tags: [agents, agent-loop, typescript, ollama]`; `series: building-an-agent-from-scratch`, `part: 1`; `draft: true`; keep the placeholder's filename (URL stays `/posts/the-loop/`) and its `pubDate` of 2026-11-10, adjusted by Vlad when he publishes.
- **Series file.** The introduction says "no agent framework" (not "no framework at all", because later Parts add Effect and SQLite) and names OpenCode as the reference the agent is checked against. `planned` becomes: The roadmap; Tools as data; Providers behind one interface; Why Effect: errors as values; Services and layers; Streaming. Stage B (Session) and Stage C (Sandbox) Parts are added when Stage A is nearly done.
