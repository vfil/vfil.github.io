# 0003 · Part 1 of the agent Series: "The agent loop"

Status: implemented (2026-11-04)

Product spec only. The Post is `src/content/posts/2026-11-10-the-loop.md` and the Series is `src/content/series/building-an-agent-from-scratch.md`; see [GLOSSARY.md](../GLOSSARY.md) for Post, Draft, Series, Part and Planned Part.

## Problem statement

Vlad's first Series, _Building an agent from scratch_, had only a placeholder Draft as Part 1. The real Part 1 already existed as a lesson written in his OpenCode fork (generated by another Claude session while exploring that repo). It teaches that a coding agent is a short loop around a model, with a hands-on build against Ollama, llama.cpp and Claude. It needed to become a Post that reads and looks like the rest of the blog.

## Solution

A faithful port of the lesson as one Post: same content, code, transcripts and sources, lightly edited for the blog. It stays a Draft until Vlad has read it and sets `draft: false`.

- The lesson-pack scaffolding (navigation, reference and glossary links, "ask Claude" paragraph) is gone. References to later lessons are "Part N" with the Planned Part title in italics.
- llama.cpp and Claude stay in the Post, marked optional. Both test environments (the build machine and the earlier wire-capture machine) are stated.
- The three "Check yourself" quizzes are interactive, like the lesson's: one attempt, right and wrong marked, a message after answering ([spec 0004](0004-quiz-component.md)).
- Agent vocabulary (provider, protocol, step, turn…) is defined inline in the Post; `GLOSSARY.md` covers the blog's domain only.
- The Series introduction says "no agent framework" and names OpenCode as the reference. Its Planned Parts are the Stage A roadmap: The roadmap; Tools as data; Providers behind one interface; Why Effect: errors as values; Services and layers; Streaming. Stage B (Session) and Stage C (Sandbox) Parts are added when Stage A is nearly done.
- Code in Posts is never reformatted by Prettier, because readers type it.

## Out of scope

Porting Parts 2 and 3, the lesson's reference pages (agent architecture, glossary), a Callout component, an agentic-AI glossary, RSS, series cover images.
