Before tools, memory or evals, an agent is just a loop. The model reads the conversation so far, decides what to do next, and the loop keeps going until the model says it is finished. Everything else in this Series hangs off this one `while` statement.

## The smallest agent I could write

```ts
type Message = { role: 'user' | 'assistant'; content: string };

interface Model {
  complete(messages: Message[]): Promise<{ text: string; done: boolean }>;
}

export async function runAgent(model: Model, task: string, maxTurns = 10): Promise<string> {
  const messages: Message[] = [{ role: 'user', content: task }];

  for (let turn = 0; turn < maxTurns; turn++) {
    const reply = await model.complete(messages);
    messages.push({ role: 'assistant', content: reply.text });

    if (reply.done) {
      return reply.text;
    }

    messages.push({ role: 'user', content: 'Continue.' });
  }

  throw new Error(`Agent did not finish within ${maxTurns} turns`);
}
```

Two things matter already. The `maxTurns` guard is not optional: without it, a confused model loops forever and spends your money doing it. And the conversation is the only state; the agent remembers nothing that is not in `messages`.
